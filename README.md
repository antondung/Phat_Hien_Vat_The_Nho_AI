# CMC AI - Exam Monitoring

This repository contains the CMC AI exam-monitoring application:

- `cmc-ai-be/cmc-ai-be/` - FastAPI backend and tests
- `cmc-ai-fe/` - React + Vite frontend

See each project's README and `.env.example` for setup instructions. Local `.env` files, runtime data, dependency/build directories, and model weight files are intentionally excluded from Git.
